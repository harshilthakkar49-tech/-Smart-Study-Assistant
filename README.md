# -Smart-Study-Assistant
AI-powered Smart Study Assistant built with Gemma 4 that helps students summarize notes, answer questions, generate quizzes, and explain difficult topics in simple language.

## Features
- Notes summarization
- Question answering
- Quiz generation
- Simple explanations
- Student-friendly learning support

## Built With
- Gemma 4
- AI / NLP
